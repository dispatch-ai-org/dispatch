# Recorded Phase 4 fixture previews

The `.ansi` files are complete output prefixes from actual macOS PTY fixture
sessions at the named milestone. They are generated by
`tests/fixtures/review_refinement.py`, using deterministic local harness fixtures.
No real model or subscription was used.

Each `.capture.json` records the scenario, milestone, timestamp offset, byte
count, dimensions and presentation environment. `.render.json` records rendering
choices. The `.txt` files contain reconstructed visible terminal cells.

The PNGs are **terminal-byte renderings, not native-terminal screenshots**.
`render-capture.py` reconstructs the control sequences actually emitted in these
captures, uses Menlo at 18 px on a chosen `#070B10` preview surface, and removes
only wholly blank rows above/below the visible content. Dispatch itself leaves
terminal background untouched. These previews cannot establish graphical
contrast in a particular native terminal, light theme or custom font.

To regenerate a PNG with an existing Python/Pillow installation:

```sh
python3 docs/captures/phase4-refinement/render-capture.py \
  docs/captures/phase4-refinement/tiny-review.ansi \
  docs/captures/phase4-refinement/tiny-review.png
```

On systems without Menlo, supply `--font /absolute/path/to/monospace-font.ttf`.
The helper accepts only the terminal-control subset needed by these captures;
it is not a production terminal emulator. No package or font installation is
part of the product.
